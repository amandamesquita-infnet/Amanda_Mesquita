# Amanda_Mesquita_DR3_TP2
Trabalho DR3 TP2 - FastAPI, Hugging Face e LangChain

Trabalho desenvolvido para a disciplina de Desenvolvimento de Data-Driven Apps, utilizando FastAPI, Hugging Face e LangChain.

Arquivos:

p1q1.py - API de geração de texto com GPT-2 e FastAPI.
p1q2.py - API de tradução do inglês para o francês com Hugging Face e FastAPI.
p2q1.py - Chatbot com Fake LLM, LangChain e FastAPI.
p2q2.py - Tradução do inglês para o francês com LangChain e Groq.
p2q3.py - Tradução do inglês para o alemão com LangChain e Hugging Face.
Amanda_Mesquita_DR3_TP2.pdf — Relatório final do trabalho.
